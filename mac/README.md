# AI 사용량 (맥)

Dock 에서 켜고 끄는 맥 앱. 창은 Codex 펫처럼 다른 창 위·모든 데스크톱·전체 화면 앱 위에 떠 있고, 눌러도 지금 쓰는 앱의 초점을 뺏지 않는다. 무엇을 보여 주고 값을 어디서 가져오는지는 [맨 위 README](../README.md).

## 켜고 끄기

- **켜기**: Dock 의 링 아이콘(또는 `~/Applications` 의 「AI 사용량」)을 누른다.
- **끄기**: Dock 아이콘 오른쪽 클릭 → 종료, 앱이 앞에 있을 때 ⌘Q, 또는 창 오른쪽 클릭 → 종료.
- **보일 칸 고르기**: 창(또는 Dock 아이콘) 오른쪽 클릭 → 「보기」 → 「세션」·「Claude」·「ChatGPT」(1.8 은 메뉴의 「○○ 보이기」). 체크를 끄면 그 칸이 빠지고 창 높이가 줄어든다(아래 모서리 자리는 그대로). 고른 것은 기억하고, Claude·ChatGPT 를 둘 다 끌 수는 없다. 숨긴 칸은 알리지 않는다. ChatGPT 칸을 끄면 5분마다 codex 를, Claude 칸을 끄면 `claude /usage` 를 띄우지도 않는다.
- **칸 순서**: 같은 메뉴(창 위쪽 메뉴 막대에도 있다) → 「보기」 → 「칸 순서」. 맨 위에 「지금: 세션 → Claude → ChatGPT」, 그 아래 「○○ 위로」를 누르면 그 칸이 한 칸 올라간다(맨 위 칸은 흐리게, 1.9 부터 — Windows 1.4.3 과 같다). 처음엔 「세션 → Claude → ChatGPT」. 바꿔도 창은 아래 모서리를 그대로 두고 높이만 맞춘다. 끈 칸은 빠지되 자리는 기억해서 다시 켜면 그 자리에 돌아온다. 오른쪽 클릭 메뉴 맨 위의 값 줄도 같은 순서. 고른 것은 앱 설정 `paneOrder` 에 남는다.
- 창을 오른쪽 클릭해 「모양」에서 표시 방식을 고르고, 떠 있는 창이면 배경 투명도·창 크기·글자 크기(각각 한 단계 더 열어 고르고 지금 값이 오른쪽에 보인다), 메뉴 막대면 작게·크게를 고른다. 지금 모드에 쓰는 것만 보인다. 선택은 다음 실행에도 유지된다.

## 한도 알림과 사용 추이

창을 오른쪽 클릭해 「알림」 → 「한도 알림」을 켜거나 끈다. 기본값은 켜짐이다. 5시간·주간 등 각 한도에서 처음 10% 이하로 남으면 한 번 알린다. 초기화 시각을 알면 그 시각부터 60분 이내에 확인한 초기화도 한 번 알린다. 초기화 시각을 모르면 첫 알림의 관측 시각에서 창 길이가 지난 뒤 새 관측부터 남은 한도를 다시 판단한다.

1.8 부터 Claude 값을 `claude /usage` 로 직접 묻는다(Windows 판과 같다, 5분마다·Claude Code 응답 직후·새로고침 때 — 자세한 것은 [맨 위 README](../README.md#값의-출처두-판-공통)). 그래서 Claude Code 도 데스크톱 앱도 안 쓰는 동안 claude.ai 에서 쓴 양도 반영된다. /usage 에 모델별 주간 한도(예: Fable)가 있으면 주간 아래에 그 모델 줄이 보인다 — 「모델별 한도 보이기 (Fable 등)」(처음엔 켬, 「칸 순서」 아래)로 숨기고, 「모델별 한도도 알림」(처음엔 끔, 「한도 알림」 아래, 한도 알림이 꺼져 있으면 흐리게)으로 그 줄도 알린다. 사용 추이와 35일 기록에는 전체 주간 한도만 들어간다. 끄기: `defaults write com.local.ai-usage-pet claudeUsage -bool false`.

「사용 추이…」를 열면 현재 계정의 주간 한도를 볼 수 있다. 「이번 주」는 지금까지의 사용률과 예상 소진 시각을, 「지난 4주」는 하루에 쓴 비율을 보여 준다. 흐린 막대는 대략적인 값이며 ↺는 초기화된 날이다. 주간 기록은 `~/.cache/ai-usage/history.jsonl`에 35일간 보관한다. 창 크기는 고정이다(1.8 부터, Windows 판과 같다).

## 세션 목록

이 맥에서 켜 둔 Claude Code·Codex 세션(터미널과 데스크톱 앱 모두)을 한 줄씩 보여 준다(3초마다). 처음엔 창 맨 위, 「칸 순서」로 자리를 바꿀 수 있다. 1.8 부터 Windows 판(1.4.1)과 같은 이름·모양·규칙이다. 세션이 늘면 창은 아래 모서리를 그대로 두고 위로 늘어난다. 위로 늘다가 화면 위 끝에 닿으면 넘친 만큼만 아래로 밀린다(기억한 자리는 그대로). 열린 세션이 없으면 칸이 없어진다. 한 줄은 「● 이름 ……… 기호 상태」 — 앞의 작은 점은 도구(주황 Claude, 초록 Codex).

| 표시 | 뜻 | 어떻게 아나 |
|---|---|---|
| 주황 ! 입력 필요 | 권한 묻기 등에서 내 답을 기다림(Claude 만) | `~/.claude/sessions/<pid>.json` 의 `status: waiting` |
| 파랑 ◌ 작업 중 N분 | 답을 만드는 중(고리가 돈다) | Claude `busy`·`shell`, Codex 기록 마지막이 `task_started` |
| 초록 ✓ 작업 완료 N분 전 | 답을 마치고 다음 지시를 기다림 | Claude `idle`, Codex 기록 마지막이 `task_complete` 또는 `turn_aborted`, 작업 중인데 그 기록 파일을 연 codex 프로세스가 없음(이 둘은 메뉴에 「(중단됨)」) |

- 순서: 입력 필요 → 작업 중 → 작업 완료, 같은 상태는 최근에 바뀐 것부터. 8개가 넘으면 7줄과 「외 N개」.
- **누르면 그 대화가 열린다**(줄에 마우스를 올리면 밝아지고 손가락 커서): Claude 데스크톱 앱 Code 탭 세션은 `claude://claude.ai/epitaxy/<hostSessionId>`, Codex 앱 대화는 `codex://threads/<대화 id>` 로 그 앱의 그 대화를, 터미널에서 연 세션은 그 세션을 띄운 터미널 앱(Ghostty·cmux·터미널 등)을 앞으로 가져온다(어느 탭인지까지는 못 고른다).
- **칸 접기**: 「세션」·「Claude」·「ChatGPT」 머리줄을 누르면 접히고 다시 누르면 펴진다(오른쪽 끝 ▲/▼, 다음 실행에도 기억 — `foldSessions`·`foldClaude`·`foldCodex`). 접은 세션은 머리줄에 「입력 1 · 진행 1 · 완료 2」(0개는 빼고, 입력 필요는 주황·작업 중은 파랑)만, 접은 Claude·ChatGPT 는 주간 막대와 남은 % 한 줄만.
- 이름: Claude 는 직접 붙인 이름(데스크톱 앱 사이드바 제목·`/rename`), 없으면 Claude 가 붙인 제목(대화 기록의 `ai-title`, /resume 목록과 같은 것), 그것도 없으면 지금 폴더. Codex 는 Codex 앱이 붙인 대화 제목(`~/.codex/session_index.jsonl` 의 `thread_name`), 없으면(CLI) 작업 폴더. 길면 끝을 줄인다. 전체 경로는 창 오른쪽 클릭 메뉴에 나온다.
  - `~/.claude/sessions/<pid>.json` 의 `name` 은 직접 붙이지 않았으면(`nameSource: derived`) 켤 때 시작 폴더로 한 번 만든 「폴더-16진수 2자리」(예: `cyborg-blog-2d`)라, 다른 폴더로 옮기거나 일이 바뀌어도 그대로다. 그래서 쓰지 않는다.
- Claude: 사람이 연 세션만 — 이 앱이 띄우는 `claude -p "/usage"` 조회와 스크립트의 `claude -p` 처럼 뒤에서 도는 실행(세션 파일의 `entrypoint: sdk-cli`, 데스크톱 앱 대화 표시 `hostSessionId` 없음)은 빠진다(1.9.1 부터, `kind` 는 이런 실행도 `interactive` 로 적혀 그것만으로는 못 가린다). pid 가 꺼졌거나 다른 프로세스가 다시 쓴 파일(`procStart` 시작 시각으로 가린다)은 건너뛴다. 세션을 닫을 때까지 보인다.
- Claude 는 뒤에서 도는 명령(백그라운드 실행)이 있으면 답을 마친 뒤에도 `busy`·`shell` 로 남는다. 그래서 대화 기록(`~/.claude/projects/…/<세션>.jsonl`) 끝에 차례가 끝난 표시(`turn_duration`)가 있으면 「작업 완료」로 본다. 오른쪽 클릭 메뉴에는 「뒤에서 명령이 아직 도는 중」이 붙는다.
- Codex: 데스크톱 앱은 대화를 처음 만든 날짜 폴더(예: `sessions/2026/10/30`)에 계속 이어 쓰므로 날짜 폴더가 아니라 최근 30분 안에 바뀐 기록과 지금 codex 가 연 기록을 본다. 작업 중인지는 그 기록 파일을 연 codex 프로세스로 안다(Windows 판은 그걸 알기 어려워 「기록이 20분 넘게 안 바뀌었거나 codex 가 없으면 중단」으로 본다). 끝난 작업은 30분 뒤 빠지고, 제목 없는 CLI 작업을 같은 폴더에서 다시 돌리면 앞의 끝난 기록은 빠진다. Codex 가 스스로 띄운 하위 작업은 보이지 않는다.
- Claude 쪽 파일은 공식 문서에 없는 형식이라 Claude Code 업데이트로 바뀔 수 있다. 모르는 상태 값은 회색 「알 수 없음」으로 보인다.
- claude.ai 웹·ChatGPT 앱 안의 대화는 보이지 않는다.
- 세션 목록만 보기: `"…/AI 사용량.app/Contents/MacOS/AIUsagePet" --sessions`(Windows `AIUsageStatus.exe --sessions` 와 같다).

## 메뉴 막대 간단 모드

1.8 부터. 창 오른쪽 클릭 → 「모양」 → 「표시 방식」 → 「메뉴 막대 (간단 모드)」, 또는 떠 있는 창을 오른쪽 두 번 클릭하면 떠 있는 창은 숨고 화면 위 메뉴 막대(시계 왼쪽)에 한도마다 동그란 게이지가 가로 한 줄로 붙는다(Windows 의 작업 표시줄 간단 모드와 같은 그림, 앱 설정 `displayMode`=1).

- 테두리 길이가 남은 비율, 가운데 숫자가 남은 %. 색은 떠 있는 창과 같은 기준(50% 이상 초록, 20% 이상 노랑, 그 아래 빨강). 회사마다 원들 뒤에 회사 색 캡슐 배경(주황 Claude, 초록 ChatGPT)을 깐다(1.9.2 부터, 그 전에는 앞의 색 점과 회사 사이 구분선). 순서와 모델별 한도(Fable 등)는 「칸 순서」·「모델별 한도 보이기」, 숨긴 칸은 빠진다. 입력이 필요한 세션이 있으면 맨 앞에 주황 「!」(「세션 보이기」를 켰을 때).
- 마우스를 올리면 「Claude · 주간 26% 남음 · 초기화 …」. 한 번 클릭하면 바로 아래로 세션 패널이 내려온다 — 줄을 누르면 그 대화를 열고, 바깥을 누르거나 Esc, 게이지를 다시 누르면 닫힌다. 오른쪽 클릭하면 떠 있는 창과 같은 메뉴(0.5초쯤 뒤), 오른쪽 두 번 클릭하면 떠 있는 창으로 돌아간다. Dock 아이콘을 눌러도 세션 패널이 열린다.
- 크기는 「모양」 → 「메뉴 막대 크기」에서 「크게」(회사 색 배경 높이가 메뉴 막대 높이에서 4pt 뺀 만큼, 원은 그보다 4pt 작게, 기본)와 「작게」(그 75%) 중에서(`menuBarSize`=100·75). 떠 있는 창의 「창 크기」·「글자 크기」와는 따로다. 메뉴 막대가 밝으면 글자·테두리를 어둡게 그린다.
- 메뉴 막대 높이는 화면에서 실제로 잰다(1.9.1 부터). macOS 27 처럼 메뉴 막대가 30pt 면 「크게」 배경 26pt·원 22pt, 「작게」 배경 20pt·원 16pt(1.9.1 은 배경 없이 원 24pt·18pt). 그 전에는 macOS 가 알려 주는 높이(`NSStatusBar.thickness`, 30pt 메뉴 막대에서도 22)를 써서 원 지름 16pt·숫자 7pt 로 작게 그려졌다. 메뉴 막대를 자동으로 숨겨 잴 수 없으면 그 값을 쓴다.
- ⌘ 를 누른 채 끌어 메뉴 막대 안에서 자리를 옮길 수 있다(기억한다). 메뉴 막대가 꽉 차면(노치 등) macOS 가 게이지를 가릴 수 있다 — 그럴 땐 Dock 아이콘 오른쪽 클릭 → 「모양」 → 「표시 방식」 → 「떠 있는 창」.

- **언어**: 창(또는 Dock 아이콘) 오른쪽 클릭 → 「설정」 → 「언어 (Language)」 → 자동(시스템 언어)·한국어·English·日本語·简体中文. 자세한 것은 [맨 위 README](../README.md#언어).
- **로그인할 때 자동으로 열기**: Dock 아이콘 오른쪽 클릭(또는 창 오른쪽 클릭) → 「설정」 → 「로그인할 때 자동으로 열기」. 켜지면 체크 표시가 붙고 시스템 설정 → 일반 → 로그인 항목에 들어간다. 다시 누르면 빠진다.

창은 끌어서 옮기고(위치 기억), 오른쪽 한 번이면 메뉴(두 번째 클릭을 기다리느라 0.5초쯤 뒤에 열린다), 오른쪽 두 번이면 메뉴 막대 간단 모드로 바뀐다(1.8 부터 Windows 판과 같다 — 왼쪽 두 번 클릭 새로고침은 없앴다. 새로고침은 메뉴의 「지금 새로고침」·⌘R). 오른쪽 클릭 메뉴에 창과 같은 순서로 세션별 상태와 폴더·마지막 값·초기화 날짜·값의 출처, 새로고침, 위치 초기화(메인 화면 오른쪽 위), 자동 실행, 업데이트 확인, 종료가 있다.

- **자동 업데이트**: 켠 뒤 1분, 그 뒤 6시간마다 저장소 Releases 에 더 높은 맥 판(`mac-v<버전>`)이 있으면 받아서 바꾸고 다시 띄운다(창이 1~2초 사라졌다 같은 자리에). 메뉴 「업데이트 확인 (지금 <버전>)」으로 바로 확인. 자세한 것·끄는 법은 [맨 위 README](../README.md#자동-업데이트). 이 맥에서 `build.sh` 로 만든 앱도 같은 규칙이라, 올라온 판보다 버전이 낮으면 올라온 판으로 바뀐다.

## Claude 값이 안 나올 때

Claude 칸에 이유가 나온다(값을 어디서 읽는지는 [맨 위 README](../README.md#값의-출처두-판-공통)).

| Claude 칸 글 | 할 일 |
|---|---|
| Claude Code 에 연결되지 않았습니다 | 창(또는 Dock 아이콘) 오른쪽 클릭 → 「설정」 → 「Claude Code 에 연결…」. 설치할 때 Claude Code 가 없었으면 이렇게 된다. 메뉴는 연결이 안 됐거나 끊겼을 때만 보인다 |
| Claude Code 연결이 끊겼습니다 | 상태 표시줄이 없는 앱 경로를 가리킨다(앱을 옮김 등). 앱이 켜질 때 묻지 않고 새 경로로 고치므로 보통은 앱을 다시 켜면 된다. 안 되면 위 메뉴 |
| Claude Code 가 한도 값을 보내지 않습니다 | 상태 표시줄은 도는데 `rate_limits` 가 안 온다. Claude 구독이 아닌 API 키·Console 로그인이거나 Claude Code 가 오래된 판 |
| Claude Code 에서 한 번 대화하면 표시됩니다 | 연결은 됐고 아직 대화 전 |

터미널에서는 `--print` 의 「출처 · Claude Code 연결」 줄과 「상태 표시줄 마지막 실행」 줄로 같은 것을 본다. `--connect` 는 메뉴의 「Claude Code 에 연결」과 같다. 프로젝트 폴더의 `.claude/settings.json` 에 다른 상태 표시줄이 있으면 그 폴더에서는 그쪽이 우선한다(이 앱은 사용자 설정만 본다).

### 추이와 알림 시험

`--trend-json --now 2026-11-20T11:09:00+09:00`은 현재 계정의 주간 점·예측과 28일 계산을 JSON으로 출력한다. `--trend-snapshot week 결과.png`와 `--trend-snapshot four-weeks 결과.png`도 같은 `--now`를 받는다. 계산 시각을 생략하면 현재 시각을 쓴다. 세 명령은 기록을 읽기만 한다.

`--test-alerts 입력.json`은 실제 알림을 보내는 대신 임시 홈의 `.cache/ai-usage/alerts.json`에 처리 결과를 저장한다. 아래 입력은 11%에서 10%로 내려갈 때의 알림과 뒤이은 초기화를 재현한다. `AIUSAGE_HOME`에는 별도로 만든 임시 폴더를 지정한다.

```json
{"steps":[
  {"now":"2026-11-20T12:00:00+09:00","provider":"codex","minutes":300,"used":89,"resetMs":"2026-11-20T16:40:00+09:00"},
  {"now":"2026-11-20T12:01:00+09:00","provider":"codex","minutes":300,"used":90,"resetMs":"2026-11-20T16:40:00+09:00"},
  {"now":"2026-11-20T16:40:00+09:00","provider":"codex"}
]}
```

`used`는 사용률이다. `now`·`atMs`·`resetMs`에는 오프셋이 있는 ISO 시각이나 Unix 밀리초를 넣는다. `account`로 계정을 고르고 `enabled`·`hidden`으로 설정을 바꾼다. 동시에 관측된 창은 한 단계의 `observations` 배열에 넣는다. 같은 임시 홈에서 명령을 다시 실행하면 저장한 알림 상태를 이어 쓴다.

`--record-once --now 2026-11-20T11:09:00+09:00`은 임시 `AIUSAGE_HOME`에서 작은 창과 같은 로컬 판독·저장을 한 번 실행한다. 서버에 접속하지 않고, 실제 추가한 주간 기록 줄 수를 출력한다. 같은 값으로 다시 실행하면 `0`이다. 최초 실행 시 35일보다 오래된 줄을 정리하므로 시험할 원천과 기록은 임시 홈에 복사해 둔다.

초기화 시각을 모르는 5시간 창은 `minutes: 300`으로 두고 `resetMs`를 생략해 시험한다. 09:00에 `used: 92`, 15:00에 `5`, 16:00에 `95`를 넣으면 09:00·16:00에 low가 발생한다. 위 예시에서 마지막 단계만 19:40으로 옮기면 16:40 초기화는 알림 없이 처리된다.

단계의 `outcome`으로 권한 거부(`denied`), 저장 실패(`saveFailure`), 전송 실패(`failed`), 전송 결과 불명(`unknown`), 권한 대기 중 숨김·계정 전환(`hideWhileWaiting`·`switchWhileWaiting`)을 재현한다. 출력의 `candidates`는 후보의 처리 결과이며 `events`는 저장한 전송·건너뜀 내역이다.

업데이트: `… --version`, `… --check-update`(올라온 최신 판만 보기), `… --update`(바로 바꾸고, 떠 있으면 다시 띄움)
창 모양은 `… --snapshot ~/Desktop/ai-usage.png`로 저장한다. 고정 표본은 `--sample`, 촬영용 모양은 `--appearance 3,130,130`처럼 배경 단계(0~3), 창 크기(85·100·115·130), 글자 크기(90·100·115·130)를 지정한다.
다른 홈 폴더로 시험(Claude Code·데스크톱 앱 파일 위치를 바꿔 볼 때): `AIUSAGE_HOME=/tmp/시험 … --print` — Windows 판과 같다.

## 다른 맥에 설치

```bash
zsh mac/package.sh   # 저장소 폴더에서 → ~/Downloads/AI사용량-mac-<버전>.zip
```

zip 이름의 버전은 `Info.plist` 의 `CFBundleShortVersionString`. 새로 건넬 묶음을 만들 때마다 먼저 그것(예: 1.4 → 1.5)과 `CFBundleVersion`(5 → 6)을 올린다. 같은 버전 zip 이 이미 있으면 덮어쓰지 않고 멈춘다.

1.4 부터는 직접 건넬 필요가 없다: `zsh release.sh mac` 이 같은 묶음을 `AIUsage-mac-<버전>.zip` 으로 Releases 에 올리고, 깔린 앱이 알아서 받아 바꾼다. 처음 까는 사람은 Releases 에서 그 zip 을 받는다.

zip 을 건네면 받는 쪽은 `읽어 주세요 (Read me).txt`(한국어·영어) 대로 터미널에 `zsh ` + `설치.sh` 끌어다 놓기 → Enter. 설치가 하는 일:

1. 앱을 `~/Applications` 에 넣고 받은 파일 표시(quarantine)를 지운다 — 개발자 인증(공증) 없는 임시 서명이라 이게 없으면 「확인되지 않은 개발자」 창이 뜬다. `.command` 더블클릭 대신 `zsh 설치.sh` 로 돌리는 것도 같은 이유.
2. Claude Code 가 있으면 `~/.claude/settings.json` 의 `statusLine` 을 앱의 `--statusline` 으로 건다(jq 불필요, 0.01초). 이미 다른 상태 표시줄이 있으면 `~/.claude/ai-usage-statusline.sh` 로 감싸 원래 줄을 그대로 보이게 하고, 원래 설정은 `ai-usage-statusline.original.json` 에 남긴다. 고치기 전 파일은 `settings.json.bak-날짜`. JSON 이 깨져 있으면 손대지 않는다. 이미 이 앱이 걸려 있는데 경로가 다르면(다시 설치·옮김) 새 경로로 고친다. 앱 안에도 같은 `claude-settings.js` 가 들어 있어서 앱의 「Claude Code 에 연결」·켤 때 고치기가 이것을 쓴다.
3. 앱을 띄우고 지금 읽히는 값(`--print`)을 보여 준다.

`지우기.sh` 는 앱·`~/.cache/ai-usage`·앱 설정을 지우고 상태 표시줄을 설치 전으로 되돌린다.

codex 는 독립 설치·Homebrew·npm(nvm·volta·bun 포함)·ChatGPT 앱에 들어 있는 것 순서로 찾는다. npm 판은 node 스크립트라 codex 가 있는 폴더를 PATH 앞에 붙여 띄운다.

이 맥처럼 직접 만든 `~/.claude/statusline.sh` 를 쓸 때는 `input=$(cat)` 뒤에 아래 한 줄을 넣어도 된다.

```bash
printf '%s' "$input" | "$HOME/Applications/AI 사용량.app/Contents/MacOS/AIUsagePet" --statusline >/dev/null 2>&1
```

## 지우기

1. 자동 실행을 켰다면 메뉴에서 끈다. Dock 아이콘 오른쪽 클릭 → 옵션 → Dock 에서 제거.
2. 앱을 끄고 `~/Applications/AI 사용량.app` 과 `~/.cache/ai-usage`(업데이트 기록 포함) 를 휴지통으로.
3. `~/.claude/statusline.sh` 에서 앱 실행 파일을 `--statusline`으로 호출하는 한 줄을 지운다. 고치기 전 원본: `~/.claude/statusline.sh.bak-20261026`.
